# Learning Log 4A - Programming

Learning Objective: Name key algorithm components.

## Task A — Sequencing, selection, iteration

Define sequencing, selection, and iteration, and give one a simple example of each from your everyday life.

### Answer guide

Sequencing = steps in order, e.g., “put grounds, pour water, then press.”

Selection = choose based on a condition, e.g., “if it’s raining, take an umbrella.”

Iteration = repeat, e.g., “stir sauce every minute for 10 minutes.”
